# Readf logo

Original/generated artwork supplied by Fayez on 2026-10-15, licensed with explicit
permission under MIT OR Apache-2.0 (LICENSE-readf.txt). The contributor confirmed
that the artwork was not copied or traced from Adobe.

Source: `ChatGPT Image Oct 15, 2026, 06_05_43 PM.png`, supplied in the project chat.
The background outside the red rounded tile was removed with imagegen at the
contributor's request. The red tile and white mark are retained.

- readf.png: transparent master PNG.
- readf-256.png: 256 px desktop icon for Linux and FreeBSD.
- readf.ico: PNG-backed Windows icon sizes 16, 24, 32, 48, 64, 128 and 256.
- readf.icns: macOS PNG-backed icon sizes 128, 256, 512 and 1024.

Platform variants only resample/package the transparent master and preserve alpha.
The welcome screen remains text-only. Earlier PdfCraft assets remain attributed
as upstream sources; Readf uses these replacement assets.
